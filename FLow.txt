Yeh Enterprise Email Agent Workspace project ek complete enterprise-grade, cognitive multi-agent AI system hai jise corporate world ki sabse badi everyday problem — yani email overload, manual calendar scheduling, aur lost deliverables — ko zero-touch aur highly secure tarike se automate karne ke liye design kiya gaya hai; aam corporate culture mein har professional apna lagbhag ek-tihai din sirf lambe-lambe email threads padhne, meetings fix karne ke liye calendar mein free slots dhoondhne, deliverables ko dhoondh kar alag to-do apps mein note karne, aur formal replies draft karne mein gawa deta hai, aur isi manual friction ko permanently khatam karne ke liye yeh platform ek simple chatbot ki tarah kaam karne ke bajaye ek multi-agent cognitive pipeline ki tarah kaam karta hai jisme har agent ka ek dedicated, specialized role hota hai aur yeh pura system Observe → Think → Act → Audit → Draft ke standard cognitive loop par operate karta hai; jaise hi koi naya corporate email system mein aata hai ya REST API ke through ingest hota hai, process ka sabse pehla step Reader Agent handle karta hai jo payload normalization ka kaam karta hai, jisme email ke andar aane wale unwanted corporate confidentiality disclaimers, legal warnings, signature blocks, redundant line endings, aur “Sent from my iPhone” jaise unwanted noise ko regex-based intelligent cleaning se remove karke ekdum clean aur structured text context downstream agents ke liye prepare karta hai; iske turant baad process Router Agent ke paas jaata hai jo Think phase ko lead karta hai aur Capgemini Generative Engine ke high-speed lightweight model Amazon Nova Micro ko strictly structured JSON output schema ke sath call karta hai taaki email ka underlying intent classify ho sake — system intent ko 5 categories mein baant-ta hai jisme pehla Meeting (jab sender appointment ya sync request kar raha ho jaise "Let's meet tomorrow afternoon"), doosra Task (jab koi deadline ya assignment di gayi ho jaise "Send the budget deck by Friday 5 PM"), teesra sabse complex Mixed Intent (jisme ek hi email ke andar meeting aur task dono mojud ho), chautha General Inquiry, aur paanchwa Ambiguous/Unknown hota hai, aur agar kabhi network issues ya LLM failure ho jaye toh Router Agent ke paas built-in deterministic heuristic rule engine hota hai jo keywords analyze karke fallback route initiate karta hai; jab intent classify ho jaata hai toh system Act phase mein pravesh karta hai jahan business use cases trigger hote hain — Case 1: The Calendar Finder ke tehat jab email mein meeting request aati hai toh Entity Extractor Agent email se specific date terms, preferred time frames, duration, topic aur participants extract karta hai aur seedha Microsoft Graph API aur MSAL authentication ke through Microsoft Outlook Calendar service ko call lagata hai, jahan se user ki free/busy availability check karke 2 se 3 best open slots nikaal kar ek structured Meeting Proposal banata hai jo Stage 1 (User Draft Review) mein stage ho jaata hai, aur user dashboard par jaise hi "Confirm Meeting" click karta hai toh yeh proposal Stage 2 mein convert hokar officially Outlook Calendar par real meeting invite book kar deta hai; Case 2: The To-Do List Creator ke dauran agar email mein koi deliverable ya action item hota hai toh Task Extractor Agent trigger hota hai jo email ko thoroughly scan karke structured task data extract karta hai — jisme concise task title, detailed description, task owner (jo default mein recipient "Me" ya named colleague hota hai), due date/time, aur strict urgency level (low, medium, high, ya urgent) shamil hota hai — aur sabse important baat yeh hai ki yeh data kisi temporary memory mein rakhne ke bajaye seedha Microsoft SQL Server (MSSQL) ke Tasks table mein ACID-compliant database record ke roop mein turant persist ho jaata hai taaki project board par koi bhi task bhoolne ka risk zero ho jaye; Case 3: The Multi-Task Router is system ka sabse powerful concurrency feature demonstrate karta hai, kyunki aksar real-world emails aisi aati hain jisme sender ek taraf budget report maang raha hota hai aur doosri taraf kal milne ki baat kar raha hota hai — traditional sequential systems mein pehle calendar check hota aur fir task save hota jisse latency double ho jaati, lekin yahan master Orchestrator Python ke asynchronous asyncio.gather pipeline ka use karke Calendar Finder Agent aur Task Extractor Agent dono ko ek hi sath concurrently parallel branches par execute karta hai, jisse bina kisi sequential delay ke ek taraf calendar slots nikal aate hain aur doosri taraf MSSQL mein tasks lock ho jaate hain; Act phase ke baad pipeline Audit phase mein aati hai jahan Supervisor Agent (Case 5: The Double-Checker) as a senior quality gatekeeper kaam karta hai aur anthropic Claude Sonnet 5 reasoning model ka use karke check karta hai ki kya email mein di gayi information actionable aur complete hai ya fir critically vague hai — agar kisi email mein time zone missing ho, date open-ended ho jaise "Let's connect sometime whenever you are free to discuss that thing", ya deliverable unspecified ho, toh Supervisor Agent pura automated workflow wahin pause kar deta hai, email status ko clarification_needed mark karta hai, database mein clarification record create karta hai, aur sender ke liye ek polite clarifying question ke sath 2 se 3 clickable, selectable multiple-choice options stage kar deta hai, jise dashboard par user sirf ek button click karke resolve kar sakta hai aur resolution aate hi paused pipeline turant aage badh jaati hai; jab saari information complete aur verified ho jaati hai tab aakhri step Reply Generator Agent (Case 4: The Smart Replier) ke paas aata hai jo extracted meeting slots aur officially logged task confirmations ko combine karke context-aware, polished executive email draft banata hai, aur isme sabse zabardast feature yeh hai ki user apni choice ke mutabiq dynamic corporate tone select kar sakta hai — chahe standard corporate etiquette ke liye Professional tone ho, warm collaboration ke liye Friendly tone ho, fast decision-making ke liye short aur crisp Concise tone ho, ya senior C-suite communication ke liye high-level Executive tone ho — aur yeh draft MSSQL ke Drafts table mein staged status mein human approval ke liye save ho jaata hai, jisse 100% Human-in-the-Loop governance ensure hoti hai yani bina user ke explicitly "Approve" aur "Send" button click kiye koi bhi email dispatch nahi hoti; is pure execution lifecycle ko monitor karne ke liye backend mein ek custom AgentSpan telemetry engine laga hua hai jo sub-millisecond precision se har agent ka execution time, input prompt, reasoning thought, output JSON, aur model used trace karta hai aur use MSSQL ke AgentLogs audit table mein permanently store karta hai, sath hi FastAPI ka native WebSocket stream (/ws/stream) continuous JSON events broadcast karta rehta hai; frontend side par Angular 19 ka high-performance, dark-themed, sleek glassmorphism dashboard banaya gaya hai jisme 3-column executive layout hai — sabse left side par ek smart Collapsible Sidebar diya gaya hai jo normal mode mein 235px par navigation links, real-time unread/task/meeting badges, aur quick + Ingest/Compose modal button show karta hai, aur ek click par smoothly shrink hokar 64px ki compact icon-only rail ban jaata hai jahan icons perfectly center aligned rehte hain aur koi bhi badge ya button overlap nahi hota, jisse prime horizontal screen space free hota hai; middle column mein Email List Deck mojud hai jahan search bar, fast intent filter chips (All, Unread, Meetings, Tasks, Mixed), aur dynamic Animated Sync Button diya gaya hai jo click hote hi 360-degree rotation aur cyan glow ke sath smooth visual feedback deta hai aur MSSQL se live data sync karke user ko confirmation toast notification dikhata hai; right column mein AI Intelligence Hub hai jise full responsive flexibility di gayi hai taaki 100% zoom par screen edge se koi bhi content cut na ho — isme top par email metadata, corporate tone selector, aur ek animated 5-step visual progress stepper hai jo WebSocket telemetry ke mutabiq step-by-step illuminate hota hai, aur neeche adaptive responsive cards grid hai jisme Original Email Content, Case 1 Proposed Calendar Slots (with Confirm button), Case 2 Logged Tasks in MSSQL (with live urgency tags aur toggleable status checkboxes), aur Case 4 Staged Email Response (with tone switcher, edit box, Approve aur Send buttons) display hote hain, aur agar Case 5 trigger ho toh interactive clarification card show hota hai jahan user quick choices select kar sakta hai; iske alawa dashboard ke navigation mein full Kanban Task Board diya gaya hai jahan MSSQL ke tasks ko Pending, In Progress, aur Completed columns mein drag-and-drop ya status toggle kiya ja sakta hai, Calendar Proposals deck hai jahan staging pipeline manage hoti hai, aur Live Agent Spans tab hai jahan enterprise administrators pure system ke execution traces aur latency metrics live monitor kar sakte hain; infrastructure and security level par yeh application enterprise-grade EnterpriseGuardrails shield se protected hai jo kisi bhi incoming payload ko models tak pahunchne se pehle inspect karti hai aur agar koi hacker ya external user prompt injection attacks jaise "ignore all previous instructions", "developer mode", ya SQL injection try kare toh use instantly block karke HTTP 400 raise karti hai, sath hi email text mein aane wale Credit Card numbers, Social Security Numbers (SSN), aur passwords ko automatically [REDACTED] tokens se mask kar deti hai aur outgoing generated replies se API keys leak hone se protect karti hai; system ka backend FastAPI, relational persistence Microsoft SQL Server (MSSQL) with ODBC Driver 18, corporate integrations Microsoft Graph API / MSAL with automatic resilient mock fallbacks, aur AI core Capgemini Generative Engine par tika hua hai jisme Amazon Nova Micro, Claude Sonnet 5, aur GPT-4o ka automatic fallback chain configure hai; overall, yeh pura project ek cutting-edge AI architecture hai jo traditional static workflows ko fully autonomous, multi-agent, highly secure, transparent, aur real-time cognitive enterprise workspace mein transform kar deta hai.
